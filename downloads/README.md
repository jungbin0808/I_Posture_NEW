# APK 다운로드

[`iposture-mvp-0.3.2.apk`](iposture-mvp-0.3.2.apk?raw=true)를 다운로드하세요. GitHub 파일 화면에서는 **Download raw** 버튼을 누르면 됩니다.

Android 7.0 이상: 다운로드한 APK 열기 → 해당 브라우저의 앱 설치 허용 → 설치 → 카메라 권한 허용.

이 APK는 테스트 버전입니다. 이전 0.3.1과 패키지·서명이 같고 버전 코드가 높아 업데이트 설치가 가능합니다. 기존 앱을 삭제할 필요가 없습니다. 앱 이름은 **아이포스처 MVP**, 패키지는 `com.iposture.personal.rebuilt`입니다. 실제 Android 휴대폰 설치·카메라 동작은 아직 검증하지 않았습니다.

체형(정면→우측면→후면), 정밀 52개 동작, 모션 관절 각도 분석, 인바디 수동 등록과 기기 내 기록 저장을 제공합니다. 자세한 범위와 빌드 방법은 [앱 소스 안내](../mobile-mvp/README.md)를 참조하세요.

SHA-256은 옆의 `.sha256` 파일에 있습니다. 저장소 루트에서 `sha256sum -c downloads/iposture-mvp-0.3.2.apk.sha256`으로 확인할 수 있습니다.

0.3.2 변경: 측정 리포트, 이전 측정 대비 수치 비교, 촬영별 관절 인식 현황, PDF 저장·인쇄를 추가했습니다. 관절 일부 또는 전체 미인식 시에도 촬영·저장할 수 있고 계산할 수 없는 항목만 ‘측정 불가’로 표시합니다.
