# APK 다운로드

[`iposture-mvp-0.3.1.apk`](iposture-mvp-0.3.1.apk?raw=true)를 다운로드하세요. GitHub 파일 화면에서는 **Download raw** 버튼을 누르면 됩니다.

Android 7.0 이상: 다운로드한 APK 열기 → 해당 브라우저의 앱 설치 허용 → 설치 → 카메라 권한 허용.

이 APK는 새로 재구성한 테스트 버전이며 기존 앱과 별도 설치됩니다. 앱 이름은 **아이포스처 MVP**, 패키지는 `com.iposture.personal.rebuilt`입니다. 실제 Android 휴대폰 설치·카메라 동작은 아직 검증하지 않았습니다.

체형(정면→우측면→후면), 정밀 52개 동작, 모션 관절 각도 분석, 인바디 수동 등록과 기기 내 기록 저장을 제공합니다. 자세한 범위와 빌드 방법은 [앱 소스 안내](../mobile-mvp/README.md)를 참조하세요.

SHA-256은 옆의 `.sha256` 파일에 있습니다. 저장소 루트에서 `sha256sum -c downloads/iposture-mvp-0.3.1.apk.sha256`으로 확인할 수 있습니다.
